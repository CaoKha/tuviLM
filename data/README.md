# Data

Reference data for features that are not ported yet. The app does not read
these files yet.

| File | What it is | Format |
| --- | --- | --- |
| `cach_cuc.yaml` | Cách cục: known star patterns, their conditions and meanings | Rules in the language of [`docs/cach_cuc_rules.md`](../docs/cach_cuc_rules.md) |
| `cau_phu.json` | Câu phú: a classic verse for each mix of chính tinh, position and Tuần/Triệt in cung Mệnh (480 cases) | JSON |

The book *Tử Vi Tân Biên* is not in git. Its files go in `data/tuvitanbien*/`,
which git ignores. Ask a maintainer for them.
